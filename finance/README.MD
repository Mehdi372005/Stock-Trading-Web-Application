# CS50 Finance – Stock Trading Web Application

## About the Project

This project was developed as part of **CS50x – Harvard University's Introduction to Computer Science**.

CS50 Finance is a full-stack web application that simulates stock trading. Users can register, log in, check current stock prices, and buy or sell stocks using virtual money.

The project helped me gain practical experience in backend development, database management, API integration, and web security.

## Features

- **User Registration & Authentication:** Implemented account registration and login functionality with secure password hashing.
- **Real-Time Stock Quotes:** Integrated a financial market API to retrieve current stock prices.
- **Stock Trading:** Users can buy and sell stocks using virtual money.
- **Portfolio Management:** Users can view their stock holdings and portfolio value.
- **Transaction History:** Records users' stock trading activities.
- **Database Integration:** Used SQLite to manage user accounts and transaction data.

## Technologies Used

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS
- **Database:** SQLite, SQL
- **API:** Financial Market API
- **Security:** Password Hashing, User Authentication
